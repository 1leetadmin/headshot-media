# Headshot Coffee media library

Photos and short videos used on Barista in a Box prospect pages and the page builder.
`media-library.json` lists every file with its industry tags.

Files are served fast from: `https://cdn.jsdelivr.net/gh/1leetadmin/headshot-media@main/media/<file>`

Add files through the Photo Inbox (`node data/add-photos.mjs` in the pitch app), not by hand.
Only library photos go here. Prospects' own photos stay private.
